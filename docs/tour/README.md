# Tour

A hands-on introductory guide for people trying ExecSandbox for the first
time. Each chapter builds on the one before it, so it's meant to be read
top to bottom (like [A Tour of Go](https://go.dev/tour/): one chapter, one
small concept). If you want an index of options, see
[`docs/usage/`](../usage/); for complete, self-contained examples by use
case, see [`docs/examples/`](../examples/).
